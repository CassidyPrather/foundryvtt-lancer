# Lancer System for FoundryVTT

**Important:** This is my personal fork. I wanted to have a version of this software that wasn't lagging so far behind the main release of foundry and wasn't full to the brim with bugs. Due to the upstream contribution policy I'm not going to bother pushing my changes there, but if maintainers in that neck of the woods want to incorporate the changes then by all means, please do. Software's AGPL or GPL or something, anyhow.

A Foundry VTT system for the [Lancer RPG](https://massif-press.itch.io/corebook-pdf) by [Massif Press](https://massif-press.itch.io/).
